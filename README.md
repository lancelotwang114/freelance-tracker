# 外包收益與排程管理 (Freelance Tracker)

一個給個人接案工作者使用的輕量網頁工具，用來取代 Google Sheet 的記帳與請款流程。

## 為什麼做這個？

原本用 Google Sheet 記錄案件、月底截圖給業主請款，痛點是：

- 月底要手動截圖、算總額
- 多個業主資料混在一起
- 手機操作不方便
- 沒有收入統計 / 報表

這個工具把上述痛點打包解決，同時保留「業主也能直接看自己那份」的能力。

## 核心功能

- **案件管理**：日期、業主、案件名稱、細項、金額、完成狀態
- **業主管理**：每個業主可設顏色、備註；可產生專屬分享連結
- **總覽儀表**：本月已完成 / 待完成、年度累計、近期案件、月度趨勢圖
- **請款單產生**：選業主 + 月份一鍵產生，可列印 / 存 PDF / 複製純文字
- **分享連結**：`?client=xxx` 讓業主看唯讀版的自己那份明細
- **資料備份**：可匯出 / 匯入 JSON

## 快速上手

1. 在瀏覽器直接打開 `index.html`
2. 第一次使用：到「設定」分頁 → 點「載入範例資料」看完整效果
3. 清空範例後，從「業主」分頁新增第一個業主，就能開始記錄案件

### 對應你原本的工作流程

| 流程 | 對應操作 |
|------|----------|
| 收到業主需求 | 「業主」分頁新增業主（只需一次） |
| 安排日期 + 明細 + 金額 | 點右下 `+` 新增案件，一次填完 |
| 給業主看 | 「業主」分頁 → 該業主的「複製分享連結」 |
| 完成打勾 | 案件前方方框一按即可 |
| 月底請款截圖 | 「請款單」分頁 → 選業主 + 月份 → 列印 / 存 PDF |

## 資料儲存

**目前版本：** 所有資料存在瀏覽器的 `localStorage`。

- 優點：無後端、免費、立刻能用
- 缺點：只存在當前瀏覽器，換裝置就看不到；清快取會遺失
- 解法：記得定期到「設定」匯出 JSON 備份；下一版會接 Google Sheet 同步

資料結構（`localStorage` key = `freelance-tracker-v1`）：

```json
{
  "clients": [
    { "id": "ab12cd", "name": "A 公司", "color": "#ef4444", "note": "月結" }
  ],
  "jobs": [
    {
      "id": "xy34ef",
      "clientId": "ab12cd",
      "date": "2026-04-15",
      "title": "首頁改版",
      "details": "首頁 + 3 內頁",
      "amount": 18000,
      "done": true
    }
  ]
}
```

## 分享連結給業主

在「業主」分頁點「複製分享連結」，會得到類似這樣的網址：

```
file:///.../index.html?client=ab12cd
```

業主打開就只看到自己那份的請款單，**不會看到其他業主資料、也無法編輯**。

若要讓業主能用網址打開（不是打開本機檔案），就需要部署到網路，參考 `docs/ROADMAP.md`。

## 開發計畫

請見 `docs/ROADMAP.md`，下一步重點：

1. Google Sheet 後端 (讓資料跨裝置同步)
2. 部署到 GitHub Pages / Vercel (業主能用網址打開)
3. 請款單客製 (LOGO、匯款資訊、稅率)
