📦 跨裝置設定檔

💡 用途：把所有設定（API URL、Token、我的資料、Calendar 設定）打包成 JSON 檔，新裝置（公司、家、手機）匯入就不用重新輸入。
⚠️ 注意：此檔案含 API Token，勿傳到 Email、聊天群組、公開雲端，建議用 USB、加密雲端、或密碼管理器（如 1Password）保管。

💡 匯入流程：在新裝置 → 設定頁 → 匯入設定檔 → 自動填好 URL+Token → 接著手動「⬇️ 從 Sheet 拉取」一次 → 啟用自動同步。
